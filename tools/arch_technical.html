Sakala AI + Mitra  ·  Technical Architecture, end to end

Everything as built (26 Oct 2026): two browser front ends, two FastAPI services, one AI layer (voice agent, intent brain, NL→SQL, understanding and routing, document reading, knowledge base, guardrails), the shared 8-stage grievance pipeline and the SQLite data layer, with every model the project uses and what it falls back to. Every model call is Google Gemini since 23 Oct 2026; Kannada is full duplex on the same live session.

Gemini only. Mitra: a 429 parks a model for 30 min, a 503 for 2 min, then the next in the chain. POC: Gemini's OpenAI-compatible endpoint, JSON schema, reasoning effort low; 429 / 5xx / timeouts fall through the chain, no network backs off 60 s to the offline model. On screen and in speech the engine is only ever “Mitra” / “Sakala AI”.
