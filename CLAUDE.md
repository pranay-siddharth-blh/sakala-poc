## 4. Domain facts (verified; cite these, don't re-derive)
**Sakala Act** (Karnataka Act 1 of 2012, originally "Guarantee of Services to Citizens", hence the GSC number; in force 2 Apr 2012):
- **s.9:** ₹20 per day of delay, capped at **₹500** per application.
- **s.11:** the Competent Officer recovers the cost from the officer at fault through a notice (Form C), with 7 days to reply. Under s.11(4) (2014 amendment) the HRMS debit note is posted within 30 days.
- **s.13:** 1st appeal to the Competent Officer within **30 days**; 2nd appeal to the Appellate Authority within **60 days**. The website FAQ's "30" refers to s.12.
- **s.14(4):** more than 7 defaults → enquiry.
- **Rules 2012:** an incomplete application gets no delivery date (the clock starts only when it is complete); public holidays are excluded; compensation is paid from imprest and then recovered; Form E-4 is the show-cause notice.
- **2026 Amendment Bill (LA Bill 28/2026):** passed the Assembly on 27 Aug 2026; Council passage and assent are unconfirmed. Adds s.13-A (government revision of appeal orders) and s.13-B (cost on vexatious complainants).

**Sakala portal (13 Oct 2026):**
- 114 departments and organisations, 1,446 services, about 43 crore receipts. New applications go through Seva Sindhu or department portals; Sakala tracks them and handles appeals.
- Call centre: 080-4455 4455. Ticker tagline: "ಇಂದು… ನಾಳೆ… ಇನ್ನಿಲ್ಲ — ಹೇಳಿದ ದಿನ ತಪ್ಪೊಲ್ಲ".

**iPGRS / Janaspandana:**
- Set up by HC order 41189/2017 and a DPAR GO; live since **1 Nov 2021**.
- Content owned by the Centre for e-Governance; built by the Centre for Smart Governance (.NET/MSSQL, hosted at KSDC). The State Level Review Committee is chaired by the CS. Helpline **1902**.
- **Routing:** a "Grievance" goes to the **LMF (Last Mile Functionary = L1)** by location, then L2, then L3. About 17,000 LMFs are mapped to GP level. A "General / PrajaSeva Request" goes to a Secretary/HoD.
- **Process rules:** an ATR is mandatory; the citizen can escalate twice. Per-level day limits are **not public** (a 2023 CM directive said 15 days).
- **Form:** 6 mandatory dropdowns, 750 characters, pin code captured.
- **Excluded topics:** RTI, sub-judice, religious, suggestions, employee service matters.

**Praja Seva Department:**
- Cabinet approval 20 Jun 2026. It merges Sakala Mission, Public Grievances and Admin Reforms. Principal Secretary Harsha Gupta was posted 3 Jul.
- **Praja Seva Abhiyana:** Saturday camps, launched 5 Sep 2026 at Kudligi; Grama One / Karnataka One counters digitise the petitions.
- **Wednesday review:** Tahsildar/EO 9–11, AC 11–1, DC 3–5.
- 11 Sep 2026: the government said it is deploying **AI routing**.
- CM D.K. Shivakumar (since 3 Jun 2026); E-Gov minister Priyank Kharge. iPGRS 2.0 was announced in June 2026.

**Sakala 2025 performance reports** (all three files identical; statewide, all departments):

- Overdue fell from 51,172 (Jan) to 19,129 (Dec), −63%.

## 7. The 8-stage pipeline (Pranay liked this flow; keep it)
1. **Entry**: one WhatsApp number; the same pipeline also serves the 1902 call centre, camps, CSC/Grama One and the app.
2. **Privacy shield**: phone, Aadhaar, email and card numbers masked.
3. **AI understanding**: Department → Line department → Service → Grievance, with confidence and reason.
4. **Completion agent**: asks only for what is missing (usually the village / GP).
5. **Validate & confirm**: location valid, duplicate check, citizen confirms.
6. **Exact-officer routing**: village → GP → named officer → escalation chain.
7. **Deadlines & reminders**: the clock starts and the escalation chain is armed (Sakala legal clock for services).
8. **Leadership view**: the case is live on the officer and Chief Secretary screens.

## 11. How to change things safely
- **App UI = wireframe + patch.** `tools/make_app_ui.py <wireframe/index.html> <tools/app_wa_client.js> <app/web/index.html>` regenerates the app UI from the wireframe.
  - The script swaps the simulated data/AI for API calls: `boot()`/`loadState()`, server-driven WhatsApp (`app_wa_client.js`), API-backed officer actions, tick and reset, Claude-or-local AI mode, and the routing-agreement KPI.
  - **Make visual changes in the wireframe, then regenerate.** If you edit `app/web/index.html` directly, regenerating will overwrite those edits.
- **Wireframe history:** `tools/patch_wa.py` (+ `wa_module.js`, `wa_future.css`) added the WhatsApp and futuristic layer. `tools/osm/` holds the map source data. `tools/make_pdf.py` and `tools/arch.html` built the PDFs and the architecture image.
- **Testing** uses headless Edge (`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`) with `--virtual-time-budget`, plus an injected `window.onerror` → `data-err` and a hook that writes `data-res` JSON.
  - App: copy `app/web/index.html` to `app/web/dbg.html` with `tools/app_tests/hook_app.txt` injected before `</body>`, then run `tools/app_tests/run_app.sh "p=citizen&flow=water" …`. Flows: water, light, apply, photo, voice, resolve, views. Each run calls `/api/reset` first. **Delete `dbg.html` afterwards.**
  - Wireframe: `tools/wireframe_tests/build_dbg.py` + `run_dbg.sh`.
  - The scripts contain hard-coded temp paths from the original session; adjust them.
- **Windows gotchas:**
  - Use `PYTHONIOENCODING=utf-8` for Kannada output.
  - Bash heredocs with backticks break; write scripts to files instead.
  - **Backslashes:** in this Bash tool `\` inside an inline heredoc arrives as a single backslash, so a Python patch containing `"\b"` writes a BACKSPACE byte into the target file (regexes silently stop matching). Write any patch that contains backslashes with the Write tool, or build them with `chr(92)`. Scan: `grep -rlP "" mitra app/server`.
  - Headless screenshots to paths with spaces fail, so render to a temp folder and copy.
  - Headless rAF and CSS transitions freeze under virtual time, so screenshots may show a half-faded splash. That's harmless.
  - Stop only your own Python processes (match `server.api:app`).
  - Re-running `python -m server.ingest` deletes and rebuilds the DB, the pristine copy and the model (about 2 minutes). Stop the server first, because the DB file is locked on Windows.
